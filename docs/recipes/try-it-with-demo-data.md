# Try it with demo data

Fill a local install with a live campaign, subscribers and funnel events.

```bash
php artisan db:seed --class="Simtabi\Laranail\WaitlistKit\Database\Seeders\WaitlistKitDemoSeeder"
```

It refuses to run in production. See [Seeders and factories](../tools/seeders-and-factories.md).
